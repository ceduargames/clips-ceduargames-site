THE PRODUCT

One desktop workspace from source video to social post

The application is designed for creators who own or are authorized to use their source footage and want control over every clip before it leaves their computer.

01

Automatic clipping

Analyze a gameplay recording for configured phrases and audio peaks, then generate vertical clips around the selected moments.

02

Highlight unification

Select several generated clips and use local analysis to identify strong segments and combine them into one edited highlight.

03

Creator review

Inspect the video, title, description, hashtags, audience setting, interaction options, and commercial-content disclosures.

04

Publishing and scheduling

Publish immediately or create a local schedule for connected accounts. Locally scheduled jobs require the computer and application to be running.

WORKFLOW

The creator remains in control

  1. 1

    Choose your footage

    Select a gameplay recording stored on the Windows computer and configure the clipping options.

  2. 2

    Generate and refine

    Review the generated clips, keep the strongest moments, or combine selected clips into a new highlight.

  3. 3

    Connect an account

    Open the platform's official authorization page. The application never asks for or receives the social account password.

  4. 4

    Review and authorize

    Confirm the destination account, final video, text, privacy, interaction settings, disclosures, and intended publication time.

  5. 5

    Publish and check status

    The application transfers the approved file through the official API and records the resulting status in local history.

TIKTOK INTEGRATION

Official authorization and direct posting

TikTok access is optional and begins only when the creator selects Connect TikTok. Authorization takes place on TikTok's own page, and the creator can deny or revoke access.

Permissions used

user.info.basic

Reads the authorized account's basic identifier and display name so the app can show which TikTok account is connected.

video.publish

Uploads and directly publishes a creator-approved video with the selected caption, privacy, interaction, and disclosure settings.

Controls before each post

  • The creator selects the video and destination account.
  • The creator reviews the caption and hashtags.
  • Current TikTok posting options are retrieved before submission.
  • The creator chooses privacy and allowed interactions.
  • Commercial-content disclosures are available when applicable.
  • A final confirmation is required before transfer.

Clips CeduarGames is an independent application and is not endorsed by TikTok. TikTok names and services belong to their respective owners.

PRIVACY AND SECURITY

Designed to minimize remote data handling

Local media processing

Gameplay files, generated clips, optional transcription, and supported AI analysis run on the user's computer.

Protected credentials

OAuth tokens and configured credentials are encrypted for the current Windows user with Windows data protection.

Purpose-limited sharing

Content and publishing metadata are sent only to a platform the creator explicitly selects for a post.

Disconnect and delete

Creators can disconnect accounts, revoke platform access, and remove locally stored application data.

SYSTEM AND AVAILABILITY

Built for Windows desktop

Clips CeduarGames runs as a desktop application on a supported Windows computer. Video processing performance depends on the source media, selected models, and available CPU, GPU, memory, and storage.

Internet access is required only for account authorization, platform option retrieval, and publishing. Local schedules require the application and computer to remain available at the scheduled time.
