Data Deletion Instructions

Disconnect accounts and remove local application data

1. Disconnect inside the Application

Open Publish or schedule → Connections, locate the platform, and select Disconnect. This removes the active local connection for that platform.

2. Revoke TikTok access

In TikTok, open Profile → Menu → Settings and privacy → Security & permissions → Apps and services permissions. Select Clips CeduarGames and choose Remove access. TikTok may change these menu names; its current instructions are available in TikTok's third-party app support article.

3. Remove local information

Delete generated clips and source videos from the folders you selected if you no longer need them. Remove the Application's local .social data folder to erase stored connection tokens, schedules, and publication history. These files belong to the current Windows user and may be hidden. Close the Application before deleting them.

If you keep system backups, deleted files may remain in those backups until the backup retention period ends.

4. Delete published platform content

Disconnecting does not delete videos already accepted or published by TikTok, YouTube, Instagram/Meta, or another platform. Delete those posts from the relevant platform account. The platform may retain records under its own legal and security requirements.

5. Website information

This static Website has no Clips CeduarGames user accounts, upload form, or application database. The Website host may retain network logs under its own policy. A public support issue can be deleted or edited through GitHub subject to GitHub's controls and retention practices.

6. Request help

If you need help identifying local data or completing these steps, use the Support page. Do not include passwords, access tokens, client secrets, or sensitive personal information in a public request.
