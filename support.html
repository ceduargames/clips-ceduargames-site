Setup, connection, publishing, and privacy help

Before publishing

  • Confirm that the selected clip opens and is the final version you intend to publish.
  • Review the destination account, title, description, hashtags, privacy, interactions, and commercial-content disclosures.
  • Use the platform connection button and finish authorization on the platform's official page.
  • For local schedules, keep the computer awake, connected to the internet, and the Application running at the scheduled time.

Connecting TikTok

Select Connect TikTok in the Connections tab. The browser opens TikTok's authorization page. Sign in directly with TikTok, review the requested permissions, and authorize the account. After the success page appears, return to the Application and confirm that the connected display name is shown.

Posting to TikTok

Select a clip, open the TikTok text panel, and use Update TikTok options before publishing. Choose one of the privacy options returned for the connected creator, select allowed interactions, complete any required commercial-content disclosure, and check the final authorization box. The History tab displays the submission result.

Common troubleshooting

The account does not connect

Confirm internet access, verify that the Application's TikTok configuration is current, and reconnect through the official authorization page. If access was previously revoked, start a new authorization.

A publication shows an error

Select the failed history item to inspect its details. Confirm that the token is valid, the video meets the platform's current requirements, and all privacy or disclosure fields are supported for that account. Reconnect when the error indicates expired or missing authorization.

A scheduled post did not run

TikTok and Instagram schedules are executed locally. Keep Windows and the Application running with an active internet connection at the scheduled time, then review the History tab.

I connected the wrong account

Use Disconnect in the Application, revoke access in the platform's settings if needed, and connect again with the intended account.

Privacy and account access

Read the Privacy Policy for details about local storage and platform transfers. To remove local information or revoke a connected account, follow the Data Deletion Instructions.

Contact support

For a reproducible problem or policy question, open a support request in the public project tracker. Include the Application version, the affected feature, the exact error message with secrets removed, and the steps that produced it.
